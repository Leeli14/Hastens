# Hastens
Building an e-commerce website for hastens electronics shop
## 🚀 Quick Start

- **Development:** `cd e_commerce && flutter run -d chrome`
- **Build web:** `cd e_commerce && flutter build web --release`
- **Deploy:** See [DEPLOYMENT.md](DEPLOYMENT.md)

### Automated Deployment
GitHub Actions workflows are configured to auto-build and deploy to:
- **GitHub Pages** (free, automatic)
- **Netlify** (free, with preview deploys)

See [DEPLOYMENT.md](DEPLOYMENT.md) for setup instructions.
